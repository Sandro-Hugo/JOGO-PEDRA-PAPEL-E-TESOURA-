# Jogo Pedra, Papel e Tesoura

Projeto desenvolvido em Python como prática de lógica de programação e fundamentos da linguagem.

O jogo permite que dois jogadores façam suas escolhas entre pedra, papel e tesoura. O programa recebe e trata as entradas, compara as escolhas e informa se houve empate ou qual jogador venceu.

## Conceitos praticados

* `print()` e `input()`
* Variáveis
* Strings
* `.lower()` e `.strip()`
* Estruturas condicionais `if`, `elif` e `else`
* Operadores de comparação
* Operadores lógicos `and`
* Construção de pseudocódigo antes da implementação

## Regras

* Pedra vence tesoura
* Tesoura vence papel
* Papel vence pedra
* Escolhas iguais resultam em empate

Projeto desenvolvido para estudo e prática de lógica de programação com Python.
